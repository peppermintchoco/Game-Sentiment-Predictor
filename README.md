# Game Sentiment Predictor
This project explores the Steam Store Games (Cleaned Dataset) on Kaggle, with the aim of exploring the game features that could result in greater positive overall player sentiment.

## Key Steps
- Data cleaning and feature engineering (Pandas)
- Eploratory data visualization and analysis (Matplotlib)
- Predictive modelling (XGBoost)
- Model evaluation using mean absolute error (MAE) values and SHAP values (SHAP)

## Tools Used
Python | Pandas | Numpy | Matplotlib | Scikit-learn | SHAP | XGBoost

## Results
The model achieved a MAE value of 0.16 and game price had the greatest influence on sentiment prediction with a mean absolute SHAP value of 0.0255.
